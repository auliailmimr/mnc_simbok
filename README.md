# Mac and Cheese Si Mbok

Landing page for Mac and Cheese Si Mbok, a homemade mac and cheese brand with outlets in Kota Batu, Malang Kota, and Dinoyo.

Live: https://auliailmimr.github.io/mnc_simbok/

## Pages

- `index.html`: landing page with the hero, menu categories, best-selling menu, brand story, Instagram feed, outlet list, and WhatsApp ordering.
- `panduan-gaya.html`: style guide with color tokens and WCAG AA contrast, typography, spacing, and the UI components used on the landing page.
- `kredit-foto.html`: photo credits and licenses.

## Stack

Plain HTML, CSS, and JavaScript. No build step. Shared design tokens and components live in `simbok.css`, and scroll animations live in `motion.css` and `motion.js`.

## Photo credits

Photos come from Wikimedia Commons under Creative Commons licenses, and the avatars come from randomuser.me. See `kredit-foto.html` for the source and license of each photo.
